# 소청초 기지 중간층 수온 연직 구조 복원

KIOST 종합해양과학기지(KORS) 관측자료를 이용해, 소청초 기지의 중간 3개 층
(7.04 m / 9.44 m / 14.74 m) 수온이 2개월간 통째로 결측된 구간을 10분 간격으로 복원합니다.

## 결과

| 단계 | Public RMSE (°C) |
|---|---|
| 주최측 수심 선형보간 기준값 | 1.290264 |
| 초기 모델 | 0.464486 |
| 물리 구조 반영 (10월 중순 이후 상부 혼합층) | 0.398512 |
| 피처·앙상블 개선 | 0.381402 |
| **전 계수 자동 적합판 (최종)** | **0.379463** |

기준값 대비 70.6% 개선. 마지막 단계에서 **수동 튜닝을 전부 제거**했더니 점수가 더 올랐습니다 —
손으로 맞춘 보정값들이 Public 분할에 과적합되어 있었습니다.

## 핵심 설계

**1. 층 번호가 아니라 실제 수심으로 정규화**

2024년은 7개 층, 2025년은 8개 층이라 같은 층 번호가 서로 다른 수심을 가리킵니다
(2024 층7 = 49.05 m = 2025 층8). `depth` 컬럼 기준으로 통일하지 않으면 두 해의 자료를
합칠 수 없습니다.

**2. 연직 형상비 φ를 타깃으로**

```
φ = (T_타깃 − T_하층앵커) / (T_표층 − T_하층앵커)
sample_weight = (T_표층 − T_하층앵커)²
```

이 가중을 쓰면 최소제곱 손실이 수온 제곱오차와 **정확히** 일치합니다. 혼합 시기에는 자동으로
편차 0이 나오고 성층기에는 형상만 학습하면 되므로 조건수가 크게 개선됩니다.

**3. 관측 불가 구간의 수축 강도를 체제 변수의 함수로 적합**

평가 구간 후반부는 19.6 m 센서가 없어 수온약층 위치를 직접 볼 수 없습니다. 예측을 표층값
쪽으로 얼마나 수축시킬지를 날짜로 정하는 대신, 계절 위상·성층강도·표층 냉각률·고주파 변동의
함수로 두고 14일 블록 교차검증 OOF 예측에 최소제곱으로 적합했습니다.

적합 결과가 독립적으로 측정한 구간별 최적값을 재현합니다:

| 상황 | 적합된 s(x) | 검증으로 측정한 최적 s |
|---|---|---|
| 강성층기 | 0.78 | 0.8 |
| 혼합기 | 0.15 ~ 0.30 | 0.0 ~ 0.2 |

## 재현성

모든 계수(계절 학습창, 이상치 임계값, 앙상블 가중, 평활창, 수축함수 8계수)는 코드에 값이
존재하지 않고 실행 중 배포 데이터로부터 적합됩니다. 사전학습 가중치와 외부 자료를 사용하지
않으며, 읽는 파일은 배포된 `observations.csv`, `test_index.csv` 두 개뿐입니다.

스레드 설정을 바꿔(`OMP_NUM_THREADS=1`, `--jobs 1`) 원자료부터 재실행한 결과, 제출 CSV와
바이트 단위로 일치했습니다.

```
MD5 18c45c88ac28447ee7e6aed0bb4dc90c   (--jobs 2)
MD5 18c45c88ac28447ee7e6aed0bb4dc90c   (--jobs 1, OMP_NUM_THREADS=1)
```
