# 문제 2 — 소청초 중간층 수온 연직 구조 복원

## 1. 요약
- **사전학습 가중치 미사용.** 배포된 `observations.csv` / `test_index.csv` 만으로 매 실행마다 처음부터 학습합니다.
- 모델: 그래디언트 부스팅 3설정 + ExtraTrees + Ridge 의 가중 블렌딩(가중치는 실행 중 적합).
- 외부 자료·외부 다운로드·중간 산출물 의존 없음. **원자료 → 제출 CSV 를 한 번에 재생성**합니다.
- 재현 시간: scikit-learn 백엔드, 2코어 기준 약 94분 (6시간 제한 내).

## 2. 실행
```bash
pip install "numpy" "pandas" "scipy" "scikit-learn"
python run_p2.py --data <P2_profile_restore 폴더> --out submission.csv --seeds 3 --jobs 2
```
- `feats.py` 를 같은 폴더에 두십시오.
- `--backend` 기본값은 `sklearn` 입니다. **제출본이 이 백엔드로 생성되었으므로 기본값을 유지하면 동일한 결과가 나옵니다.**
- `--sim` : 2024년 가을에 실제 테스트와 동일한 가림을 재현하는 내부 검증만 수행.
- `--fast` 는 개발용 축소 탐색이므로 재현 시 사용하지 마십시오.
- 실행 환경 버전은 `VERSIONS.txt` 참조.

## 3. 모델 설계
### 3.1 층↔수심 정규화
2024년은 7층(39m 센서 없음), 2025년은 8층이라 **같은 층 번호가 연도별로 다른 수심**을 가리킵니다
(2024 층7 = 49.05m = 2025 층8). 배포 데이터의 `depth` 컬럼 기준으로 d04/d07/d09/d15/d19/d31/d39/d49 로 통일합니다.

### 3.2 φ 파라미터화
수온을 직접 회귀하지 않고 연직 형상비를 예측합니다.
```
φ = (T_타깃 − T_하층앵커) / (T_표층 − T_하층앵커),   표본가중 = (T_표층 − T_하층앵커)²
```
이 가중을 쓰면 최소제곱 손실이 **수온 제곱오차와 정확히 일치**합니다(항등식이며 튜닝이 아닙니다).
혼합 시기에는 자동으로 편차 0이 나오고, 성층기에는 형상만 학습하면 되어 조건수가 크게 개선됩니다.
앵커는 층5(19.59m)가 있으면 층5, 없으면 층6(30.68m)입니다.

### 3.3 피처 (약 640개, 전부 공개 층에서 계산)
- 조석 6개 조화성분(M2/S2/K1/O1/M4/MSf), 연주기 3차 조화
- 층간 lag/lead ±10분~48시간, 이동평균 대비 편차, 이동표준편차
- 수심 선형보간 6종 + PCHIP 곡률 보간, 그 값들의 위상차
- 등온선 깊이 isoz(Δ), 밀도 σt·부력진동수 N²·밀도기준 혼합층깊이 mld(Δσ)
- **타깃 수심 상대 피처** `z_타깃 − isoz`, `z_타깃 − mld`, 정규화 위치
  (트리 모델은 뺄셈을 스스로 만들지 못하므로 명시적으로 제공)
- 가림 구간에도 배포된 `depth` 컬럼으로 타깃 층의 조석 순간수심을 사용

**타깃 층(2·3·4)의 `temp`/`psal` 은 어떤 피처에도 사용되지 않습니다.**

### 3.4 층5 결측 구간
2025-10-14 20:10 이후는 층5(19.59m)가 없어 수온약층 위치를 직접 관측할 수 없습니다.
이 구간의 예측을 표층값 쪽으로 얼마나 수축시킬지를 **관측 가능한 체제 변수의 함수**로 적합합니다.
```
δ_true ≈ δ_pred · (x · w)
x = [상수, sin(2π·doy/365.25), cos(2π·doy/365.25), T(4m)−T(31m), T(31m)−T(49m),
     T(4m) 24시간 변화, T(4m) 72시간 변화, T(4m) 10분차 절대값의 24시간 평균]
```
계수 w 는 배포 데이터를 14일 블록으로 나눈 **블록 교차검증 OOF 예측**에 대한 능형 최소제곱으로 구합니다
(표본 약 86,000 / 파라미터 8). **날짜 리터럴이 없습니다** — 혼합·성층 전이는 냉각률과 성층강도로 자동 판정됩니다.

적합된 함수가 내놓는 값은 독립적으로 측정한 구간별 최적값과 일치합니다:
2024-09 강성층 0.78(측정 0.8) · 2024-10 하순 혼합 0.30(측정 0.2) · 2025-10 하순 혼합 0.15.

## 4. 실행 중 적합되는 값
| 값 | 절차 |
|---|---|
| 계절 학습창 | 후보 격자를 2024년 가상 가림 검증 RMSE 로 선택 |
| 이상치 임계 | 잔차 절대편차의 99% 분위수 |
| 앙상블 가중 | 검증 예측에 대한 비음수 최소제곱(NNLS) |

| 층5 결측 구간 수축함수 | 블록 교차검증 OOF 에 대한 능형 최소제곱 |
